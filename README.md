# Baseshift

`Baseshift` is a single-screen Flutter iOS app for converting integer values between binary, decimal, octal, and hexadecimal.

## Features

- Convert between binary, decimal, octal, and hexadecimal in any direction.
- Swap input and output bases with one control.
- Validate input based on the selected number base.
- Support negative integers and large values with Dart `BigInt`.
- Use a clean, single-screen interface with a Frutiger Aero-inspired color palette.

## Tech Stack

- Flutter
- Dart
- Material 3
- Dart `BigInt`
- Flutter widget tests
- iOS Simulator through Xcode

## Project Structure

```text
lib/main.dart          Main app UI and conversion logic
test/widget_test.dart  Widget tests for empty state and validation
ios/                   iOS project files
android/               Android project files generated by Flutter
```
